# AiOnlineRuler — Accurate On-Screen Ruler

[AiOnlineRuler](https://aionlineruler.com/) is a lightweight, calibrated web-based measurement tool designed to turn any desktop or mobile display into an accurate physical ruler.

## Live Website
👉 **Try it here:** [https://aionlineruler.com/](https://aionlineruler.com/)

---

## Features
- **True Physical Scale:** Calibrated 1:1 scale for real-world measurements.
- **Multiple Units:** Measure in millimeters (mm), centimeters (cm), and inches (in).
- **Display Calibration:** Quick standard credit-card sizing calibration to ensure screen pixel accuracy.
- **No Installation Required:** Completely browser-based, instant loading, and mobile-friendly.

---

## Use Cases
- Measuring small daily objects against the screen.
- Screen size verification and pixel density calibration.
- Quick physical dimension checks without a physical ruler.
